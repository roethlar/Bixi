# Governance remediation

Use the findings supplied by refresh and current repo evidence. Work in
the current agent when available; a new session is not required.

Apply objective corrections within existing authority. Present only
unsettled choices with the affected file, evidence and recommendation.
Related findings may share a ruling; do not ask again for an approved fix.
A leave-it ruling gets an inline
`<!-- lint: allow (reason) -->` so it does not prompt on every refresh.

Scope is repo-owned governance records and the authorized findings.
Toolkit-owned copies route to their source; product changes need their
own scope. Preserve unrelated work.

Verify changed guidance with `refresh.py --lint-only`; do not rerun
installation. Commit the authorized corrections together and push per
policy. Report remaining substantive findings, then finish. No separate
commit approval when already covered and no wait for an end-session word.
