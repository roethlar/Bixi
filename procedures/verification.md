# Governance verification

Check that the drafted guidance lets a new session find the project purpose,
current work/blockers, next action, verification/closeout requirements and
homes for state and decisions. Reuse inspected evidence and deterministic
checks; verify changed or uncertain claims, not every historical fact.

The approval plan checks installation paths and content. Use a disposable
local rehearsal clone when the migration has an unresolved installation
risk; test only that risk and the affected changes after a fix. Do not
automatically repeat clones, installs or model calls.

An unprimed fresh-agent discoverability check is optional and requires an
explicit owner request. If requested, give that agent only the proposed
files at their intended paths and the questions above. Do not prime answers.
Missing facts should be reported, not guessed. This checks discoverability
and consistency; external-system claims still need actual evidence.

Use existing verification results for unchanged inputs. Record the checks
and any material limitation briefly in the existing summary. Remove only
disposable scratch created for this task under existing cleanup authority.
