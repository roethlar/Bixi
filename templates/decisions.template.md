# Agent Decisions

Record settled decisions or unresolved choices that lack another canonical
home. Give the rule/question, supporting evidence, consequences and any
superseded rule in plain words. No required status spelling or empty form.

Use an existing source citation instead of duplicating provenance. Archive
settled rationale under `docs/history/decisions-archive.md` when it obscures
active guidance; retain one archive pointer. A candidate finding changes
no process until adopted.
