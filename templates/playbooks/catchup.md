# Playbook: `catchup`

Restore current context from AGENTS.md, repo guidance, state and relevant
active records. Reuse content and freshness checks already valid in context.
Read only what the current work needs, including local agent configuration
when relevant; do not enumerate archives by default.

Tidy objectively stale records encountered during this pass using
`.agents/playbooks/drift.md`. Skip an unchanged record. No automatic
cleanup-agent prompt or launch: delegation requires an explicit request
and a useful independent task. Perform small authorized cleanup directly.

Report the state, blockers and next action briefly. Ask only for unresolved
choices. Do not start unrelated implementation. An ordinary status request
needs a concise status answer, not this whole procedure.
